## 一、灯光控制类

### get_brightness_temperature

- 获取台灯的亮度和色温
- 调用 **POST /light/getlt** 接口
    - 无请求参数
    - 无请求体
    - 返回示例：`"brightness:50,temperature:70"` 格式的字符串，包含当前亮度和色温值

### brightness_up

- 调高台灯亮度
- 调用 **POST /light/brightness** 接口
    - 请求参数：
        - `command`：1（调高亮度）
        - `value`：调整幅度，可选，默认值为10
    - 无请求体
    - 返回示例：`"Sent: (brightness_up,10)"` 表示命令已发送成功

### brightness_down

- 调低台灯亮度
- 调用 **POST /light/brightness** 接口
    - 请求参数：
        - `command`：2（调低亮度）
        - `value`：调整幅度，可选，默认值为10
    - 无请求体
    - 返回示例：`"Sent: (brightness_down,10)"` 表示命令已发送成功

### light_temperature_up

- 调高台灯色温
- 调用 **POST /light/temperature** 接口
    - 请求参数：
        - `command`：3（调高色温）
        - `value`：调整幅度，可选，默认值为10
    - 无请求体
    - 返回示例：`"Sent: (tem_up,10)"` 表示命令已发送成功

### light_temperature_down

- 调低台灯色温
- 调用 **POST /light/temperature** 接口
    - 请求参数：
        - `command`：4（调低色温）
        - `value`：调整幅度，可选，默认值为10
    - 无请求体
    - 返回示例：`"Sent: (tem_down,10)"` 表示命令已发送成功

## 三、闹钟管理类

### create_one_time_alarm

- 创建一次性闹钟

- 调用 **POST /api/alarms/create** 接口

    - 无请求参数

    - 请求体：

        ```json
        {
          "userId": "user123",
          "alarmTime": "07:30",
          "type": 1,
          "targetDate": "2026-01-22",
          "tag": "起床"
        }
        ```

        | 字段 | 类型 | 必填 | 说明 |
        |------|------|------|------|
        | userId | String | 是 | 用户ID |
        | alarmTime | String | 是 | 闹钟时间，格式 HH:MM 或 HH:MM:SS |
        | type | Integer | 是 | 闹钟类型，1 表示一次性闹钟 |
        | targetDate | String | 是 | 目标日期，格式 YYYY-MM-DD |
        | tag | String | 否 | 闹钟标签，如"起床"、"开会" |

    - 返回示例：
        - 成功：`"闹钟创建成功"` 或 `"闹钟已存在，已更新时间"`
        - 失败：`"用户ID不能为空"` 或其他错误信息

### create_recurring_alarm

- 创建循环闹钟

- 调用 **POST /api/alarms/create** 接口

    - 无请求参数

    - 请求体：

        ```json
        {
          "userId": "user123",
          "alarmTime": "07:00",
          "type": 2,
          "repeatDays": "1,2,3,4,5",
          "tag": "工作日起床"
        }
        ```

        | 字段 | 类型 | 必填 | 说明 |
        |------|------|------|------|
        | userId | String | 是 | 用户ID |
        | alarmTime | String | 是 | 闹钟时间，格式 HH:MM 或 HH:MM:SS |
        | type | Integer | 是 | 闹钟类型，2 表示循环闹钟 |
        | repeatDays | String | 是 | 重复日期，1=周一...7=周日，多个用逗号分隔 |
        | tag | String | 否 | 闹钟标签 |

    - 返回示例：
        - 成功：`"闹钟创建成功"`
        - 失败：`"参数不完整"` 或其他错误信息

### delete_one_time_alarm

- 删除一次性闹钟
- 调用 **DELETE /api/alarms/{alarmId}** 接口
    - 请求参数：
        - `alarmId`：闹钟ID（路径参数）
        - `userId`：用户ID（查询参数）
    - 无请求体
    - 返回示例：

        ```json
        {
          "code": 200,
          "message": "闹钟删除成功",
          "success": true
        }
        ```

### delete_recurring_alarm

- 删除循环闹钟
- 调用 **DELETE /api/alarms/{alarmId}** 接口
    - 请求参数：
        - `alarmId`：闹钟ID（路径参数）
        - `userId`：用户ID（查询参数）
    - 无请求体
    - 返回示例：

        ```json
        {
          "code": 200,
          "message": "闹钟删除成功",
          "success": true
        }
        ```

## 四、睡眠数据类

### get_sleep_report_one_day

- 获取指定日期的睡眠报告
- 调用 **GET /api/sleep/summary** 接口
    - 请求参数：
        - `date`：查询日期，格式 YYYY-MM-DD（必填）
        - `userId`：用户ID，默认值 "user123"（可选）
    - 无请求体
    - 返回示例：

        ```json
        {
          "query_date": "2026-01-20",
          "sleep_time": "2026-01-20 22:30:00",
          "wake_time": "2026-01-21 07:15:00",
          "sample_count": 1050,
          "light_sleep_duration_min": 180.0,
          "deep_sleep_duration_min": 180.0,
          "rem_duration_min": 90.0,
          "total_sleep_min": 450.0,
          "avg_heart_rate": 32.5,
          "avg_breathing_rate": 8.5,
          "wake_count": 1,
          "wake_start_times": ["2026-01-21 03:20:00"],
          "message": null
        }
        ```

        | 字段 | 类型 | 说明 |
        |------|------|------|
        | query_date | String | 查询日期 |
        | sleep_time | String | 入睡时间 |
        | wake_time | String | 清醒时间 |
        | sample_count | Integer | 采样记录数 |
        | light_sleep_duration_min | Double | 浅度睡眠时长（分钟） |
        | deep_sleep_duration_min | Double | 深度睡眠时长（分钟） |
        | rem_duration_min | Double | REM睡眠时长（分钟） |
        | total_sleep_min | Double | 总睡眠时长（分钟） |
        | avg_heart_rate | Double | 平均心率（次/半分钟） |
        | avg_breathing_rate | Double | 平均呼吸频率（次/半分钟） |
        | wake_count | Integer | 起床次数 |
        | wake_start_times | Array | 清醒段起始时间列表 |
        | message | String | 提示信息（无数据时返回说明） |

## 五、助眠音乐控制类

### play_sleep_music

- 播放助眠音乐
- 调用 **POST /sleep-music/control** 接口
    - 请求参数：
        - `action`：`start`（或 `play`、`on`）
    - 无请求体
    - 返回示例：

        ```json
        {
          "success": true,
          "message": "助眠音乐播放命令已发送",
          "command": "(sleep_music_start,0)"
        }
        ```

### stop_sleep_music

- 停止播放助眠音乐
- 调用 **POST /sleep-music/control** 接口
    - 请求参数：
        - `action`：`stop`（或 `pause`、`off`）
    - 无请求体
    - 返回示例：

        ```json
        {
          "success": true,
          "message": "停止助眠音乐命令已发送",
          "command": "(sleep_music_stop,0)"
        }
        ```

### next_music

- 播放下一首音乐
- 调用 **POST /sleep-music/switch** 接口
    - 请求参数：
        - `direction`：`next`（或 `下一首`）
    - 无请求体
    - 返回示例：

        ```json
        {
          "success": true,
          "message": "下一首命令已发送",
          "command": "(sleep_music_next,0)",
          "direction": "next"
        }
        ```

### prev_music

- 播放上一首音乐
- 调用 **POST /sleep-music/switch** 接口
    - 请求参数：
        - `direction`：`prev`（或 `previous`、`上一首`）
    - 无请求体
    - 返回示例：

        ```json
        {
          "success": true,
          "message": "上一首命令已发送",
          "command": "(sleep_music_prev,0)",
          "direction": "prev"
        }
        ```
